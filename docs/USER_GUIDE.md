## 0. 這是什麼

Studio 是一個在本機執行的網頁介面。影片生成不在你的電腦上跑，而是透過 Google Colab CLI 租用雲端 A100 GPU，跑 MiniMax H3 影片模型，完成後把 MP4 下載回本機的 `outputs/` 資料夾。

- **你的電腦需要**：Windows（其他系統未測）、Python 3.12、網路。不需要顯示卡。
- **你需要的帳號**：一個有 Colab 算力點數（Compute Units，CU）的 Google 帳號。CU 為 0 的帳號申請不到 A100。
- **模型組成**：MiniMax H3 原模型（INT8 量化版）、官方 Turbo 4 步加速 LoRA；換人模式再加掛社群 Character Swap LoRA V1.5。

## 1. 安裝與第一次啟動

### 1.1 下載專案並安裝套件

```bash
git clone https://github.com/pondahai/minimax-h3-studio.git
cd minimax-h3-studio
pip install -r requirements.txt
```

`requirements.txt` 已包含 Colab CLI（`google-colab-cli`）。

### 1.2 確認 `colab` 指令可以執行

開一個**新的**終端機，執行：

```bash
colab --help
```

如果出現「無法辨識 colab」：

- 用 Microsoft Store 版 Python 安裝時，`colab.exe` 會裝在下面這個資料夾，而這個資料夾預設不在 PATH 裡：
  `%LOCALAPPDATA%\Packages\PythonSoftwareFoundation.Python.3.12_*\LocalCache\local-packages\Python312\Scripts`
- 把這個資料夾加進「使用者環境變數」的 Path，**關掉並重開終端機**後再試一次。已經開著的終端機讀不到新的 PATH。

### 1.3 登入 Google 並確認算力

Colab CLI **沒有** `colab login` 這個指令。第一次執行需要授權的指令時，它會自動開瀏覽器讓你登入：

```bash
colab usage
```

在瀏覽器選擇有 CU 的 Google 帳號並同意授權，完成後終端機會顯示：

```text
Current balance: 357.66 compute units
Usage rate: 0.00/hr
Active assignments: 0
```

- **餘額是 0**：可能登入了錯誤的帳號。刪掉 `%USERPROFILE%\.config\colab-cli\token.json`，再執行一次 `colab usage`，這次在瀏覽器點「使用其他帳戶」。
- **要購買 CU**：執行 `colab pay`，會打開購買頁面。

### 1.4 選用元件

| 元件 | 什麼時候需要 | 怎麼確認 |
|---|---|---|
| [ffmpeg](https://ffmpeg.org/) | [長片分段換人](#43-長片分段換人) | `ffmpeg -version` 有輸出 |
| OpenAI 相容的 LLM 伺服器 | [LLM 擴寫提示詞](#53-llm-擴寫內建) | 預設連 `http://100.89.149.50:8002/v1`，見 [5.3](#53-llm-擴寫內建) |

### 1.5 啟動 Studio

雙擊專案資料夾裡的 `start_studio.bat`，或在終端機執行：

```bash
python app.py
```

接著用瀏覽器開 **http://localhost:7860**。關掉這個終端機視窗，Studio 就會停止。

## 2. 介面總覽

畫面分成三欄：

| 位置 | 內容 |
|---|---|
| **頂部** | 三個模式分頁（🎭 Ref2VA 全模態、🎬 FL2VA 首尾過渡、✍️ T2VA 純文字），以及右上角的 Colab 算力餘額與每小時費率 |
| **左欄：素材** | 影像資產（1～9 張圖）、音色克隆資產（1～3 段音訊）、參照影片（1～3 支）、換人模式勾選框 |
| **中欄：提示詞** | LLM 導演提示詞工坊、導演分鏡時間軸、LLM 擴寫提示詞、「檢視 / 自由編輯完整 Prompt」 |
| **右欄：執行** | 秒數（4～15 秒）、GPU 規格、畫面比例、「啟動 Google Colab 雲端生成」按鈕、進度條與日誌、成果播放器、歷史生成庫 |

### 素材和提示詞標籤的對應

上傳的素材會依上傳順序自動編號，提示詞裡用標籤指稱：

| 素材 | 標籤 | 說明 |
|---|---|---|
| 第 1～9 張圖 | `<Picture 1>` ～ `<Picture 9>` | 可以拖曳、點擊上傳，或直接 Ctrl+V 貼上截圖 |
| 第 1～3 段音訊 | `<Audio 1>` ～ `<Audio 3>` | MP3／WAV，2～15 秒乾淨人聲 |
| 第 1～3 支影片 | `<Video 1>` ～ `<Video 3>` | MP4／MOV，2～15 秒，原聲一併帶入 |
| 台詞 | `<d>[Chinese] 台詞 </d>` | 也可以用 `[English]` |

### 提示詞從哪裡來

送出時，Studio 會依下面的順序決定提示詞：

1. 「檢視 / 自由編輯完整 Prompt」欄位**有內容**：直接用這段文字。
2. 欄位**是空的**：用「導演分鏡時間軸」的欄位（主體定義、留存特徵、各分鏡、音景、配樂）自動組成一段提示詞，並填回這個欄位。

### 共通的生成步驟

每種工作流最後都是這幾步：

1. 在右欄設定**秒數**（4～15 秒，預設 12 秒）、**GPU 規格**（建議 A100）、**畫面比例**（上傳直式影片時會自動切成直式）。
2. 按「啟動 Google Colab 雲端生成」。
3. 看進度條：申請 GPU → 上傳素材 → H3 取樣 → 下載成果 → 安全關機。
4. 完成後影片會自動播放，檔案存在 `outputs/`，也會出現在「歷史生成庫」。

要中途停止，按「緊急中斷並關閉 Colab 虛擬機」。Colab 會立刻釋放，不會繼續扣 CU。

> ⚠️ 右欄顯示的「預估耗時約 4.5 分鐘｜~1.1 CU」是固定文字，不會隨秒數或模式改變。實際時間請參考 [第 6 節](#6-時間與算力參考)。

## 3. 生成模式

### 3.1 Ref2VA 多參照生成

**適用情境**：你有角色或場景的參考圖，想生成一段全新的影片，例如讓參考圖裡的人在某個場景說一句話。

**素材**：1～9 張參考圖，例如角色正面照、服裝、場景。可另外加音訊（見 [4.1](#41-音色克隆)）或影片。

**步驟**

1. 頂部選「🎭 Ref2VA 全模態」。
2. 在「影像資產」上傳參考圖。
3. 寫提示詞，三種方式擇一：
   - 用「導演分鏡時間軸」逐欄填寫。
   - 用 [LLM 擴寫](#53-llm-擴寫內建)，寫一句中文構想就好。
   - 直接在「檢視 / 自由編輯完整 Prompt」寫英文提示詞。
4. 設定秒數和比例，按「啟動 Google Colab 雲端生成」。

**提示詞寫法**：用 `<Picture N>` 指出誰是誰，例如「The woman from `<Picture 1>` walks into the café shown in `<Picture 2>`」。

### 3.2 FL2VA 首幀生成

**適用情境**：你要影片的第一個畫面就是某張圖，讓畫面從這張圖開始動起來。

**素材**：1 張圖，會當成影片的第一幀。

**步驟**

1. 頂部選「🎬 FL2VA 首尾過渡」。
2. 上傳 1 張圖。
3. 寫提示詞，描述畫面接下來怎麼動、鏡頭怎麼移動。
4. 設定秒數，按生成。

**和 Ref2VA 的差別**：Ref2VA 的參考圖只用來決定角色和風格，畫面構圖會重新生成；FL2VA 的第一幀就是你給的那張圖。

### 3.3 T2VA 純文字（目前不能用）

介面上有「✍️ T2VA 純文字」分頁，但**目前無法使用**：前端和後端都要求至少上傳 1 張圖，沒有圖就送不出去；就算上傳了圖，後端也會把它當成 Ref2VA 處理。只想用文字生成的話，請改用 Ref2VA 並上傳一張風格參考圖。

## 4. 進階工作流

### 4.1 音色克隆

**適用情境**：要影片裡的人用某個特定的聲音講話。

**素材**：參考圖，加上一段 2～15 秒的乾淨人聲（MP3／WAV），不要有背景音樂。

**步驟**

1. 用 Ref2VA 模式，上傳參考圖。
2. 在「音色克隆資產」上傳人聲，它會對應到 `<Audio 1>`。
3. 在分鏡的「角色台詞」輸入台詞，聲音選「🎙️ Audio 1 音色」。或者在提示詞裡寫：「S1 speaks with the voice of `<Audio 1>`, saying, `<d>[Chinese] 台詞</d>`」。
4. 按生成。模型會模仿這段聲音的音色、音調和口音，並讓嘴型對上台詞。

### 4.2 短片換人

**適用情境**：把一支影片裡的某個人換成另一個角色，同時保留原片的鏡頭、背景、其他人、動作和原聲。

**素材**

- **原片**：2～15 秒，建議 4～8 秒、中間沒有剪接的連續鏡頭。
- **角色圖**：1 張，最好是清楚的全身或半身照。正面照也可以用，但原片人物側面或背對鏡頭時，臉會比較不像。

**步驟**

1. 用 Ref2VA 模式。
2. 在「影像資產」上傳角色圖（成為 `<Picture 1>`），在「參照影片」上傳原片（成為 `<Video 1>`）。原片是直式的話，畫面比例會自動切成直式。
3. 勾選「換人模式」。
4. 寫提示詞，建議用 [LLM 擴寫](#53-llm-擴寫內建)，構想寫成例如「把開槍的男人換成參考圖的女生，連服裝一起換，她舉散彈槍瞄準左上方的飛靶開槍」。提示詞要包含這幾點：
   - 要換掉的是誰，例如「the shooter in the gray jacket」。
   - 保留參考角色的臉、頭髮和服裝。不寫的話，模型可能沿用原片的衣服。
   - 具體描述原片人物的動作。模型不會自動照抄動作，要寫出來。
   - 保留場景、鏡頭、其他人和原聲。
5. 確認秒數和原片差不多（上傳影片時已自動設成原片長度，無條件進位），按生成。

**限制**

- **一次只能換一個人**。要換多人只能一個一個換：把換好的影片當原片再換下一個人，但每換一輪畫質都可能再下降。
- 特寫時，表情可能跟不上原片。
- 原片上的字幕和貼圖可能會消失。

**實測**：射擊場直式影片，9 秒，換成穿泳裝的女生，連服裝也換掉了，教練和場景都有保留。推論約 9.3 分鐘，全程約 13 分鐘。

### 4.3 長片分段換人

**適用情境**：原片超過 15 秒，一次跑不完。

**事前準備**：本機要裝好 ffmpeg（見 [1.4](#14-選用元件)）。

**步驟**

1. 用 Ref2VA 模式，勾選「換人模式」。
2. 上傳角色圖，最多 8 張，因為要留一格給段落之間的接續畫面。
3. 上傳超過 15 秒的原片。會跳出提示：「會自動切成 N 段（每段約 X 秒）」。**這時只能上傳這一支影片。**
4. 寫一段換人提示詞，它會套用到每一段。**建議直接寫在「檢視 / 自由編輯完整 Prompt」**：分鏡時間軸的時間點是依整支影片算的，對不上每一段。
5. 按生成。進度條會顯示「第 i/N 段 · …」。

**背後的流程**

1. 用 ffmpeg 把原片平均切成 N 段，每段不超過 8 秒。例如 23.8 秒會切成 3 段，每段 7.92 秒。
2. 只開一次 Colab，在同一個環境裡依序跑每一段，不必每段都重新安裝、下載模型。
3. 從第 2 段起，把上一段在切點的畫面加成最後一張 `<Picture N>`，提示詞也會自動加上「開頭要和這張圖一致」。
4. 每段生成完後裁回原片段的長度，再全部接成 `outputs/long_*_full.mp4`。
5. 中途取消或任何一段失敗，都會關掉 Colab。

**限制**

- **接縫處會跳**：接續畫面只是參考圖，不是強制的第一幀，模型會照原片那段的鏡頭重新構圖。實測接縫處人物位置會左右偏移，播放時看得出來。
- 每一段的臉和身形可能略有差異。
- 這個流程目前只用假資料測過，還沒在 Colab 上完整實跑。

### 4.4 尾幀接續

**適用情境**：把一段影片延伸下去，讓下一段從上一段的最後一個畫面開始。

**步驟**

1. 影片生成完後，按播放器下方的「🔄 以此影片結尾接續下一鏡」。
2. Studio 會擷取最後一幀，**取代所有參考圖**成為唯一的圖，並自動切到 FL2VA 模式。
3. 寫下一段的提示詞，按生成。
4. 各段影片目前要**自己用剪輯軟體接起來**，Studio 沒有合併功能。

**限制**

- ⚠️ **換人模式下不要用這個按鈕**。它會丟掉角色圖、切到 FL2VA，換人模式也就失效了。換人影片要延長，請改用 [長片分段換人](#43-長片分段換人)。
- 下一段的動作只靠提示詞決定，不會延續原片。

### 4.5 時間軸錨點（只有 API）

可以把某張圖或某段音訊固定在影片的某個時間點出現。後端已經支援，但**網頁上還沒有操作介面**，只能透過 API 或批次 manifest 使用（manifest 裡 job 的 `guides` 欄位）。詳細欄位請看 `scripts/runner.py`。

## 5. 寫提示詞的輔助工具

H3 的提示詞要用英文寫，並遵守標籤格式。Studio 提供三種輔助方式：

### 5.1 導演分鏡時間軸

在中欄逐欄填寫：主體定義、留存特徵、每個分鏡的開始秒數和描述、運鏡（推進、橫搖、跟隨）、角色台詞、整體音景、配樂。按「新增分鏡」可以加鏡頭。送出時，如果「完整 Prompt」欄位是空的，Studio 會把這些欄位組成一段提示詞。

### 5.2 LLM 導演提示詞工坊（外部 LLM）

適合想用 ChatGPT、Claude 或 Qwen 網頁版寫分鏡的人。

1. 在工坊輸入故事構想，按「複製 LLM 提示詞」。Studio 會依你上傳的素材，自動組好一段指令。
2. 貼到外部 LLM，它會回傳分鏡 JSON。
3. 複製 LLM 的回覆，按「貼回解析」並貼上，再按「⚡ 自動解析並填入所有欄位」，分鏡時間軸就會自動填好。

### 5.3 LLM 擴寫（內建）

一鍵把中文構想擴寫成完整的英文提示詞，不必複製貼上。

1. 先上傳素材、勾好換人模式、設好秒數。擴寫時會參考這些設定。
2. 在「LLM 擴寫提示詞」寫一句中文構想。留空的話，會改成潤飾「完整 Prompt」欄位裡現有的內容。
3. 按「✨ 擴寫成完整 Prompt」，約 20～40 秒後，結果會填進「完整 Prompt」欄位。構想裡有「換」、「替換」等字、又上傳了影片，但沒勾換人模式時，會先問你要不要開啟換人模式。
4. 檢查並修改後再送出。

**注意**

- LLM 會**看到你的參考圖（最多 4 張）和第一支影片的 6 張畫面**，依畫面描述場景和動作，不會憑空編造。LLM 不支援看圖時，會自動改成只送文字，這時道具、動作、要換的是誰都要寫在構想裡。
- 換人模式下，它會自動套用作者建議的寫法。

**設定**（環境變數，啟動 Studio 前設定）

| 變數 | 預設 | 說明 |
|---|---|---|
| `H3_LLM_BASE_URL` | `http://100.89.149.50:8002/v1` | 任何 OpenAI 相容的伺服器，例如 llama.cpp、Ollama（`http://localhost:11434/v1`）、LM Studio（`http://localhost:1234/v1`） |
| `H3_LLM_MODEL` | 空白 | 空白時用伺服器上的第一個模型 |
| `H3_LLM_API_KEY` | 空白 | 雲端服務才需要 |
| `H3_LLM_VISION` | `1` | 把參考圖和影片畫面送給 LLM；設成 `0` 只送文字 |
| `H3_LLM_THINKING` | `1` | 推理模型先推理再作答，品質較好，約 30～40 秒；設成 `0` 約 2 秒，但寫得比較簡略 |

## 6. 時間與算力參考

以下都是 A100 的實測數據：

| 任務 | 推論時間 | 全程 |
|---|---|---|
| Ref2VA，12 秒，無影片 | 約 4～5 分鐘 | — |
| Ref2VA，12 秒，加 1 支參照影片（未開換人） | 421 秒 | 約 10.5 分鐘 |
| 換人，5 秒 | 191 秒 | 約 7 分鐘 |
| 換人，7 秒 | 411 秒 | — |
| 換人，9 秒 | 561 秒 | 約 13 分鐘 |
| 換人，15 秒 | **超過 26 分鐘，被自動中止** | — |

- 每次開 Colab 的準備時間約 3 分鐘：安裝約 30 秒、下載模型約 2 分鐘、啟動 ComfyUI 約 25 秒。
- 推論時間不是跟秒數成正比，而是隨長度大約**平方**成長。**換人超過 10 秒時，請改用長片分段換人。**
- 單次執行上限 25～26 分鐘，超過就會自動中止並釋放 Colab，避免浪費 CU。中止前用掉的時間仍然會扣 CU。
- CU 參考：Ref2VA 12 秒約 1.1 CU。實測換人 3 次成功加 1 次超時，合計約 6.2 CU。
- 換算成台幣：A100 約 NT$0.37／分鐘，換人 9 秒約 NT$5。完整估算見 [成本估算](COST_ESTIMATE.md)。

## 6.5 模型來源與備份

每次開 Colab 都會重新下載模型和程式，來源如下。為了避免上游更新後專案壞掉，所有來源都**鎖定在 2026-10-22 實測可用的版本**：

| 來源 | 內容 | 鎖定版本 |
|---|---|---|
| HF `Comfy-Org/MiniMax-H3` | 主模型、文字編碼器、VAE、Ref2VA Turbo LoRA | `e5eb578a89` |
| HF `akatz-ai/MiniMax-H3-Character-Swap-LoRA` | 換人 LoRA V1.5 | `96ea3407b2` |
| HF `drbaph/MiniMax-H3-Turbo-Lora-ComfyUI` | FL2VA Turbo LoRA | `bb2bc497cb` |
| GitHub `Comfy-Org/ComfyUI` | 推論引擎 | `1a82e6d01f` |
| GitHub `ComfyUI-VideoHelperSuite` | 讀取影片的節點 | `4d907bee61` |

想改回每次抓最新版（例如要測試上游的新功能），啟動 Studio 前設定 `H3_PIN_UPSTREAM=0`。

### 備份到 Google Drive（防止來源被刪除）

1. 確認 Google Drive 有足夠空間：Ref2VA 加換人約 **39 GiB**，再加 FL2VA 約 **84 GiB**。免費版只有 15 GB，需要 Google One。
2. 在終端機執行備份。它會開一台 CPU 的 Colab（不用 GPU），把鎖定版本的模型從 HF 直接下載到 `我的雲端硬碟/minimax-h3-models/`：
   ```bash
   python scripts/backup_models.py
   ```
   要連 FL2VA 模型一起備份的話，加上 `--with-fl2va`；只想先看會備份哪些檔案，加上 `--dry-run`。
3. **第一次執行**時，終端機會出現一個 Google Drive 授權網址。用瀏覽器開啟並同意授權，再回到終端機按 Enter。
4. 已經備份過的檔案會自動略過，中斷後重新執行就會接著備份。
5. 啟動 Studio 前設定 `H3_DRIVE_FALLBACK=1`。之後每次開 Colab 都會先掛載 Drive；只有在 HF 下載失敗時，才改從 Drive 複製模型。HF 正常時速度不受影響。

> ⚠️ 備份腳本和 Drive 備援目前只做過本機模擬測試，還沒在 Colab 上實際跑過。每次掛載 Drive 也會多花幾秒到幾十秒。

## 7. 常見問題

**Q：按生成後一直停在「申請 GPU」？**
A100 滿載時，Colab 會直接拒絕（503），而且沒有排隊機制。被拒時不會扣 CU，稍後再試，或改用 L4。

**Q：出現「另一個影片生成任務正在進行中」？**
一次只能跑一個任務。等它跑完，或按「緊急中斷並關閉 Colab 虛擬機」。

**Q：換人後還穿著原片的衣服？**
在提示詞裡明確寫「keep the reference character's face, hair and clothing from `<Picture 1>`, not the [原片服裝]」。

**Q：上傳的影片被移除了？**
不是換人模式的話，影片限 2～15 秒。超過 15 秒的影片只有換人模式能用，會自動分段處理。

**Q：LLM 擴寫失敗？**
確認 LLM 伺服器連得上，例如用瀏覽器開 `http://100.89.149.50:8002/v1/models`。換其他伺服器請設定 `H3_LLM_BASE_URL`。

**Q：生成的影片存在哪裡？**
在 `outputs/` 資料夾。每支 MP4 旁邊都有一個同名的 `.json`，記錄提示詞、模式、是否開換人、比例、要求秒數、用了哪些素材、seed 和各階段耗時。結果不如預期時，先看這個檔案。

**Q：寫了中文提示詞，結果和想的完全不一樣？**
H3 的提示詞要用英文，並用 `<Picture 1>`、`<Video 1>` 等標籤指出素材，只有台詞能用中文。中文構想請先用「LLM 擴寫提示詞」轉成完整的英文提示詞。要換人的話，也記得勾選「換人模式」，並把秒數設成和原片差不多。
