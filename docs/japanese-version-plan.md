# 科學天地動畫 日文版製作計畫

建立：2026-11-02。以《蝴蝶》日文版（`projects/comic-video/butterfly_ja/`）的經驗為範本，把其餘篇目做成日文配音＋日文字幕版。

## 原則（沿用《蝴蝶》做法）

1. **只重配聲音，不重做畫面**：影片、配樂沿用中文版目錄；日文版目錄 `<篇名>_ja/` 只放 `config.json`、`storyboard.md`、`audio/`、字幕與成片。
2. **時段不動、台詞縮短**：日語約 7–8 拍/秒，比中文長；每句先算拍數，超出原時段就刪修飾語、拆句或省略，不改秒數。動物叫聲（阿柴等）不配音。
3. **角色名片假名化**：小明→ミン、小美→メイ、旁白→ナレーター；其他角色依《蝴蝶》慣例取片假名（例：林博士→リン博士、小宇→ユウ）。`speakers`、`voices` 的 key 都換成日文名。
4. **參考音沿用中文版**：使用者已選定的中文參考音直接拿來跨語言克隆（`ref_*.wav`），不重新挑音色；有新角色才走候選人工挑選。
5. **全句假名讀音表**：`config.json` 的 `pronounce` 為每句含漢字的台詞提供全假名版本送 TTS（字幕仍顯示原句）。注意助詞「は」要寫成「わ」才唸對（如「たまごわ」）。
6. **`t2s: false`**：日文不可走 OpenCC 轉簡體。
7. **字幕**：`sub_font: "Noto Sans CJK JP"`，`tagline` 改日文（《蝴蝶》為「観察・尊重・保護」）。
8. **畫面禁字規則照舊**；不用重跑 H3，所以不受 TTS／H3 互斥影響，可在 H3 空檔以外隨時配音。

## 每篇流程

1. 複製中文版 `config.json` → `<篇名>_ja/config.json`，改 `title`、`voices`、`speakers`、`tagline`、`sub_font`、`t2s`、`note`。
2. 翻譯 `storyboard.md` 台詞（只留「秒／畫面—／聲音」三欄，格式供 `tts.py` 讀取），逐句檢查拍數。
3. 產生 `pronounce` 全假名對照。
4. 使用者確認譯稿與角色名後才配音。
5. TTS 配音 → ASR 核對：**漏字也算壞句**、轉成別的語言（例如混進中文）算壞句；壞句每句重配 3 版給使用者挑，最後以人工試聽為準。
6. 檢查音訊時間軸（每 0.5 秒），確認每句落在原時段、不壓到下一句。
7. 合成 `_sub.mp4`（日文字幕）與 `_share.mp4`，用 `review.py --lite` 給使用者手機審查。

## 已知風險（《蝴蝶》與中文版教訓）

| 風險 | 對策 |
|---|---|
| 跨語言克隆在短句、並列詞上不穩，混進怪音 | prompt 模式克隆＋ASR 篩選；短句可加語氣詞撐長度 |
| 漢字讀錯（音讀／訓讀） | 一律送全假名，不送漢字 |
| 台詞超出時段 | 翻譯階段就算拍數，不靠加速 |
| 中文版原生音軌混人聲 | 合成時照中文版一樣靜音原生音軌 |

## 建議順序

1. 先做台詞少、角色與《蝴蝶》重疊的篇目：**凝結、影子、月食**——驗證林博士的日文名與克隆效果。
2. 再做 **日食、彩虹、聲音、四季**。
3. 角色全新的 **電池、飛機** 最後做，新角色要先跑候選音色確認跨語言效果。
4. **密度** 等中文版補完 share 版。
