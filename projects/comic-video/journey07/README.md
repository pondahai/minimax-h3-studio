# 現代西遊大冒險 第七集：悟空與AI的奇妙體驗（2026-11-06 開始）

來源：社子文教基金會「現代西遊記」第七集（`https://shezi.org.tw/assets/images/panels/journey-07/`，header＋panel-01～12，原圖存 `source/`；網站沒有 full.png）。副標「善用AI・不盲從・用思考創造更好的未來」。本集重點：認識AI是什麼、體驗AI的能力、學會正確使用、辨別假資訊、發揮創意與合作。
